# КЕГЭ (ЕГЭ по информатике): устройство КИМ и формат ответа по каждому номеру

Источник — только официальные материалы ФИПИ, скачанные прямой ссылкой
`https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/<год>/inf_11_<год>.zip`:

* `ИНФ-11 ЕГЭ 2027 СПЕЦ.pdf` / `ДЕМО.pdf` / `КОДИФ.pdf` — проект КИМ-2027,
  подготовлен 21.08.2026 (это раскладка для тех, кто сдаёт в июне 2027 г.);
* `ИНФ-11 ЕГЭ 2026 СПЕЦ.pdf` / `ДЕМО.pdf` — действующая раскладка 2026 года.

Никакие сторонние сайты (РешуЕГЭ, 4ege, math100) источником здесь не являются.
ВАЖНО: открытый банк ФИПИ (`tasks.json`) для №26 и №27 содержит ЛЕГАСИ-задания
доэкзаменационной эпохи («Вы можете сдать одну или две программы… оценивается
экспертом» — 67 из 74 у №27). Формат ответа по ним определять НЕЛЬЗЯ, только по
демоверсии.

## Общее устройство (2026 и 2027 одинаково)

* 27 заданий, ВСЕ — с кратким ответом, все выполняются за компьютером.
  Части 2 (развёрнутого ответа, фото решения, проверки экспертом) в КЕГЭ НЕТ.
* Проверка целиком машинная: «Ответы на все задания КИМ оцениваются
  автоматизировано» (СПЕЦ, п. 10).
* Продолжительность — 3 часа 55 минут (235 минут).
* Задания 1–25 — по 1 баллу, задания 26 и 27 — по 2 балла.
  Максимум первичного балла — **29**.
* Уровни сложности: Б — 11 заданий, П — 11, В — 5.
* Доступны текстовый редактор, редактор электронных таблиц и системы
  программирования; интернет запрещён.
* У 26 и 27 ответ вводится в ЯЧЕЙКИ таблицы, и есть частичный балл: если числа
  переставлены местами или верно только одно из двух — 1 балл.

## Что изменилось в 2027 году (СПЕЦ, п. 11, дословно)

1. Структура КИМ не менялась.
2. Тематика задания 10 «Информационный поиск средствами текстового процессора»
   изменена на «Умение использовать маску подсети».
3. Тематика задания 13 «Умение использовать маску подсети» изменена на «Умение
   анализировать ход исполнения алгоритма».
4. Тематика задания 23 «Умение анализировать ход исполнения алгоритма» изменена
   на «Умение решать алгоритмические задачи, связанные с анализом графов (задачи
   построения оптимального пути между вершинами графа, определения количества
   различных путей между вершинами ориентированного ациклического графа)».
5. Изменена структура записи ответа задания 27: строка из двух чисел вместо двух
   строк по два числа.

То есть по сути номера сдвинулись по цепочке 13 → 10, 23 → 13, а на 23 встало
НОВОЕ задание про графы; задание «поиск в текстовом документе» из КИМ исчезло.
