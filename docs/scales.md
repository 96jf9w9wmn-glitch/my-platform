# Системы оценивания экзаменов

Код — `src/examScales.js` (единственная точка правды). Здесь — откуда взяты
цифры и чем каждая подтверждена. **Проверено 28.08.2026, шкалы 2026 года.**

Правило: ни одна цифра не попадает в код без подтверждения ДВУМЯ независимыми
источниками. Таблицы перевода Рособрнадзор утверждает ежегодно весной, после
досрочного этапа, — при смене года сверять заново и править только
`src/examScales.js`.

## Что такое первичный и вторичный балл

**Первичный** — сумма баллов за задания по спецификации ФИПИ. Вне своего
экзамена он ничего не значит: 20 первичных в ОГЭ и в ЕГЭ — разные вещи.

**Вторичный** — то, что человек получает на руки:

| Экзамен | Вторичный балл |
|---|---|
| ЕГЭ математика профиль | тестовый, из 100, по таблице |
| ЕГЭ информатика (КЕГЭ) | тестовый, из 100, по таблице |
| ЕГЭ математика база | только отметка 2–5, тестового балла не бывает |
| ОГЭ математика | отметка 2–5 |
| ОГЭ информатика | отметка 2–5 |

Шкала тестового балла неравномерная: первые первичные баллы «стоят» в разы
дороже последних. Считать её процентом нельзя.

## Что проверяет машина, а что эксперт

| Экзамен | Автоматически | Эксперты |
|---|---|---|
| ОГЭ математика | 1–19 (бланк ответов № 1) | 20–25 (бланк № 2) |
| ОГЭ информатика | 1–12 | 13–16 (сдаются файлами) |
| ЕГЭ база | 1–21 | — |
| ЕГЭ профиль | 1–12 (бланк № 1) | 13–19 (бланк № 2) |
| ЕГЭ информатика (КЕГЭ) | 1–27, включая 26 и 27 | — |

Дословно из спецификации ЕГЭ профиля: «Оценивание правильности выполнения
заданий, предусматривающих краткий ответ, осуществляется с использованием
специальных аппаратно-программных средств»; «Проверка выполнения заданий 13–19
проводится экспертами на основе разработанной системы критериев оценивания».
Ответ в бланк № 1 засчитывается, только если совпал с эталоном И записан в
указанной форме, — поэтому формат ответа на экзамене значит столько же, сколько
сам ответ.

Работу с развёрнутыми ответами независимо проверяют ДВА эксперта. Третья
проверка назначается, если расхождение по любому заданию — 2 и более балла,
либо расхождение сумм за всю часть 2 — 3 и более балла, либо один эксперт
увидел ответ, а другой посчитал, что ответа нет.

## Особенность КЕГЭ

ЕГЭ по информатике с 2021 года сдают только за компьютером. Бланков ответов
нет вообще: ответы вводятся в станцию КЕГЭ, и **все 27 заданий проверяются
автоматически** — экспертов-предметников в проверке нет. Задания 25–27 требуют
написать программу, но в ответ идёт только результат её работы; сама программа
не сдаётся. Поэтому у КЕГЭ в платформе нет «части 2» и формы выставления
баллов репетитором.

А вот ОГЭ по информатике устроен иначе, и до 28.08.2026 здесь стояло обратное:
задания 13–16 сдаются готовыми файлами (презентация или текстовый документ,
электронная таблица, программа или алгоритм для Робота) и «проверяются и
оцениваются экспертами предметной комиссии» — спецификация ФИПИ 2026. Они дают
9 первичных баллов из 21 и с 28.08.2026 перечислены в `PART2_NUMBERS`. В наши
варианты эти номера всё равно не идут: для них нужен компьютер, а не лист.

## Критерии оценивания части 2

Лежат в `src/examCriteria.js` и показываются репетитору прямо в форме проверки
варианта: у номера части 2 вместо надписи «макс. N» стоит кнопка «из N», она
разворачивает лестницу баллов ФИПИ. Там же кнопка «общие требования» — правила,
которые эксперт применяет к любому номеру (решение должно быть полным, ответ
без решения — 0 баллов, особенности записи не учитываются).

Формулировки перенесены дословно из демоверсий ФИПИ 2026. Обобщены ровно два
места, где ФИПИ ссылается на конкретную задачу демоварианта: в №15 профиля
(«исключением точки ½» → «исключением отдельной точки») и в №18 («точек
a = −9 и/или a = 3» → «граничных точек»). Сама лестница баллов при этом не
меняется — на экзамене эксперт видит её же, только с числами своей задачи.

Критериев ОГЭ по информатике здесь нет намеренно: они расписаны под конкретный
подвид задания (13.1 презентация против 13.2 текста, 15.1 Робот против 15.2
программы) и без текста задачи бесполезны; в варианты эти номера не входят.
Демоверсия ОГЭ по информатике на 2026 год к тому же помечена «ПРОЕКТ».

Связность критериев с разбалловкой проверяется машинно — верхняя ступень
критерия обязана совпадать с максимумом задания, а лестница идти без дыр:

```bash
node --input-type=module -e "import { PART2_NUMBERS, taskMaxOf } from './src/examScales.js'; import { criteriaOf } from './src/examCriteria.js'; for (const [t, ns] of Object.entries(PART2_NUMBERS)) for (const n of ns) { const c = criteriaOf(t, n); if (c && c[0].score !== taskMaxOf(t, n)) console.log('расхождение', t, n) }"
```

## Прогноз по неполному варианту

Собранный платформой вариант почти всегда короче настоящего экзамена: в него
идут только задания, решаемые на бумаге. Максимумы наших вариантов:

| Экзамен | Вариант | Экзамен целиком |
|---|---|---|
| ОГЭ математика | 31 | 31 |
| ЕГЭ профиль | 12 + собранная часть 2 | 32 |
| ЕГЭ база | 12 | 21 |
| ОГЭ информатика | 10 (№1–10) | 21 |
| ЕГЭ информатика | 17 | 29 |

Поэтому вторичный балл по такой работе — **прогноз**: первичный приводится к
шкале экзамена по доле выполнения, и в интерфейсе он помечен знаком `≈` и
подписью. Показывать его без пометки нельзя: 17 из 17 в нашем варианте КЕГЭ —
это не 29 первичных баллов.
