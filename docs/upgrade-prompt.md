# ПРОМТ: апгрейд Precettore по разбору конкурентов

> Это рабочее техзадание-промт. Его можно скормить целиком или брать блоками (V/A/F/B/M/C).
> Каждый пункт содержит **конкретную ссылку на сайт-источник** — перед реализацией
> открыть ссылку и посмотреть оригинал своими глазами, а не делать «по описанию».
> Дата сбора источников: 2026-07-27.

## 0. КАК ИСПОЛНЯТЬ ЭТОТ ПРОМТ

1. Работать **по одному пункту за раз**. Пункт = один коммит.
2. Перед началом пункта — открыть ссылку-источник в браузере (`preview_start` / `navigate`)
   и посмотреть оригинал. Скопировать *приём*, а не пиксели.
3. После правки — проверить в живом приложении (`npm run dev`, порт 5174), снять скриншот,
   проверить светлую И тёмную тему, десктоп И мобильный вьюпорт (375×812).
4. Готовый и проверенный пункт — сразу `npm run build` + `npm run lint` → коммит → push в `main`
   (автодеплой Vercel на precettore.ru). Не копить в рабочем дереве.
5. Проверять правку **по всему приложению**, а не только на показанном экране: если меняется
   компонент/класс — пройтись по всем страницам, где он используется.
6. Чертёжные/визуальные задания и любые изменения генераторов заданий — **по одному, с показом
   пользователю и утверждением**, до перехода к следующему.

## 2. ЖЁСТКИЕ ПРАВИЛА (нарушать нельзя)

1. **Тёмная тема — класс `.dark` на `<html>`.** В `.dark` серые токены Tailwind
   ИНВЕРТИРОВАНЫ: `gray-100/200` = тёмный фон, `gray-800/900` = светлый текст.
   Не угадывать — смотреть `src/index.css:32-100`. Вариант `dark:` работает
   (`@custom-variant dark` объявлен), но кастомные цвета лучше через `.dark .foo`.
2. **Всё кликабельное анимируется** при нажатии/наведении. Для широких элементов —
   `.press-fill` (заливка-оверлей), НЕ `scale` (даёт зазоры). Статичных кнопок быть не должно.
3. **Премиально, не дёшево.** Запрещено: плоские белые карточки + насыщенные кнопки во всю
   ширину. Нужно: стеклянные карточки, аватары, мягкие тонированные чипы с кольцом,
   компактные градиентные пилюли-CTA.
4. **Отступы — с воздухом.** Проверять глазами расстояние между заголовком, блоком и подписью
   и внутри карточек ДО показа пользователю. Пустот под короткой колонкой не допускать:
   не CSS-columns, а flex-колонки в grid + `items-stretch` + `flex-1` на нижней карточке.
5. **Формулы не переносятся на следующую строку** — формула целиком в одной строке
   (`noBreakMath()` в `src/utils.js`, класс `.tmath-nb`).
6. **Дроби — стоячие** (`fT` / токен `⟦f⟧`), не через «/». Соответствия — только через
   `⟦match⟧`/`matchBlock`. Графики — в `solution_image`, не в условие.
7. **Генераторы заданий не ломать.** Любая правка `taskGenerators*.js` = прогон
   (skill `fipi-smoke`) + при затрагивании полноты — `coverage.py`. Статус «готово»
   только после машинной проверки.
8. **Новые таблицы Supabase — сразу с RLS.** RLS на старых таблицах (`students`,
   `homework`, `notifications`, `pending_students`, `variant_submissions`, `boards`)
   ещё выключен — это известный долг, НЕ включать его походя внутри этих задач.
   Новые таблицы делать сразу правильно: RLS + доступ ученика только через
   SECURITY DEFINER RPC с проверкой `session_token`.
9. **Не показывать пользователю `.svg`** — конвертировать в PNG:
   `qlmanage -t -s 660 -o . file.svg`.
10. **Деплой** готовой проверенной работы — обязателен (коммит + push в `main`).

### БЛОК A — АНИМАЦИЯ

> Общие правила: длительность 180–420ms, easing `cubic-bezier(.2,.8,.2,1)`,
> обязательный `@media (prefers-reduced-motion: reduce) { animation: none; transition: none; }`.

#### A1 · Счётчики цифр при въезде в вьюпорт
- **Источник:** блоки статистики https://www.drfrost.org/ и https://sparxmaths.com/
- **Спека:** `IntersectionObserver` (threshold 0.4), счёт 0 → значение за 1200ms
  с ease-out, срабатывает один раз. Моноширинные цифры (`font-variant-numeric: tabular-nums`),
  чтобы блок не дёргался.

#### A2 · Мгновенная реакция на верный ответ
- **Источник:** https://brilliant.org/ — в превью урока под задачей появляется «Good work.»
- **Файлы:** `StudentDashboard.jsx`, `Homework.jsx`, `Practice.jsx`.
- **Спека:** при верном ответе — мятная галочка масштабом 0.8→1 с лёгким overshoot (240ms)
  + подпись «Верно» с `.slide-up`; при неверном — горизонтальный shake 160ms, БЕЗ красной
  заливки всего поля (не пугать ученика).

#### A3 · Пружина у стикер-бейджей
- **Источник:** https://matvoyce.tv/ — стикеры «пружинят».
- **Спека:** появление `scale(.85) rotate(-8deg)` → `scale(1) rotate(-3deg)`, 260ms,
  `cubic-bezier(.34,1.56,.64,1)`.

#### A4 · Круглая кнопка-стрелка с уезжающей стрелкой
- **Источник:** https://yutu.ru/ru/for-users/tutors — карточки базы знаний с зелёной круглой
  кнопкой-стрелкой в углу.
- **Спека:** при hover/press стрелка `translateX(3px)`, круг чуть темнеет. На тач-устройствах —
  реакция на `:active`.

#### A5 · Переход «список → карточка» как движение камеры
- **Источник:** https://uncommonstudio.com.au/ (переходы-камера между секциями);
  референс плавности — https://by-kin.com/
- **Файлы:** `Students.jsx` → `StudentProfile.jsx`, использовать существующие
  `.page-active` / `.view-back`.
- **Спека:** уходящий список `scale(.98)` + `opacity .6`, входящая карточка от позиции
  нажатой строки; назад — обратно. 320ms.

#### A6 · Взвешенный smooth-scroll лендинга
- **Источник:** https://by-kin.com/ (описан как «weighted smooth scroll»; вживую движение
