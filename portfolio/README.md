# Личный сайт-портфолио репетитора

Отдельная статическая страница, не связанная с приложением: `index.html` + фото.
Ни сборки, ни зависимостей — открывается двойным кликом и кладётся на любой хостинг
как есть.

## Что обязательно заменить перед публикацией

Все места помечены в `index.html` комментарием `ЗАМЕНИТЬ`.

1. **Отзывы** — сейчас в блоке «Что говорят ученики и родители» стоят
   **демонстрационные** тексты, чтобы показать вёрстку. Их нужно заменить на
   настоящие: публиковать выдуманные отзывы нельзя.
2. **Цифры** — полоса фактов в первом экране и блок «Что получается на выходе»
   заполнены демо-значениями.
3. **Цены** — блок «Занятия и стоимость».

Контакты уже настоящие: телефон, телеграм и почта лежат в объекте `CONFIG` в самом
низу файла и оттуда подставляются в кнопку звонка, WhatsApp, телеграм и почту.
Больше нигде не дублируются — менять только там.

## Заявки

Форма пишет в ту же таблицу `leads`, что и лендинг платформы, с пометкой
`source: "портфолио"` — заявки видны в CRM (`crm.precettore.ru`) вместе с
остальными. Адрес базы и публичный `anon`-ключ лежат в `CONFIG`; ключ публичный по
своей природе (он и так есть в бандле сайта), приватного в файле ничего нет.

Проверено: preflight с любого домена проходит (`access-control-allow-origin: *`),
политика `leads_public_insert` разрешает анонимную вставку. Живую отправку одной
заявки стоит прогнать руками после публикации.

Если запрос не прошёл, форма не молчит: показывает ссылку на телеграм и почту.

## Локальный просмотр

```bash
python3 -m http.server 4180 --directory portfolio
```

Затем открыть <http://localhost:4180>. Заведена и конфигурация `portfolio`
в `.claude/launch.json`.

## Публикация

Страница самодостаточная: нужны только `index.html` и `arman.jpg` в одной папке.
Внешних CDN нет намеренно — шрифты системные, поэтому никакие данные посетителей
не уходят на сторонние домены (важно для 152-ФЗ).

Например, на свой сервер рядом с основным сайтом:

```bash
rsync -av portfolio/ precettore-db:/opt/precettore-web/portfolio/
```

и отдать папку отдельным блоком Caddy (поддомен или путь `/me`).

## Технические заметки

- Тёмная тема без светлого варианта — решение осознанное: фото снято на чёрном фоне
  и вклеено через `mix-blend-mode: screen`, поэтому фон снимка растворяется в
  странице. При замене фото нужен такой же кадр на **чёрном** фоне, иначе появится
  видимый прямоугольник.
- Блоки появляются по скроллу через `IntersectionObserver`; если скрипт не
  выполнится, содержимое всё равно видно (класс `.js` на `<html>` + страховка по
  таймеру).
- `prefers-reduced-motion` учтён: анимации и счётчики отключаются.
